## Featured Projects

### [CineMatch](https://github.com/Bandoof/CineMatch)

**Movie & TV discovery · Python / Streamlit / scikit-learn / SQLite**

- Ukrainian/English search, ratings, watchlists, and a local library.
- Implements several recommendation approaches, including matrix factorization and genre-based discovery.
- The public demo uses **real metadata and genre heuristics**; ML modes require a separate local data/model pack.

[Live demo](https://try-cinematch.streamlit.app/) · [Repository](https://github.com/Bandoof/CineMatch)

### [digit-recognizer](https://github.com/Bandoof/digit-recognizer)

**Handwritten digit recognition · Python / TensorFlow / OpenCV / Tkinter**

- Desktop CNN app with a drawing canvas, image upload, and webcam input.
- Reproducible training, evaluation reports, and batched inference.
- A separately trained model reached **99.09% on the official MNIST test set** without test-time augmentation. This result does not describe the bundled legacy model or real-world webcam accuracy.

[Repository](https://github.com/Bandoof/digit-recognizer) · [Evaluation results](https://github.com/Bandoof/digit-recognizer/blob/main/reports/README.md)
