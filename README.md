## Featured projects

### 🎬 [CineMatch](https://github.com/Bandoof/CineMatch) — Movie & TV Discovery

A bilingual **Ukrainian/English** Streamlit app for discovering movies and series, exploring recommendation methods, and managing a personal library.

**Stack:** Python · Streamlit · scikit-learn · SQLite · GitHub Actions

- Collaborative filtering, item-neighbor, content-based, and optional semantic recommendation modes.
- Reproducible research workflows using MovieLens data.
- Automated tests, CI checks, and engineering documentation.
- **Live demo:** public metadata and genre-based discovery; the full ML model pack is provisioned separately for local use.

**[▶ Live demo](https://try-cinematch.streamlit.app/)** · **[Source & documentation](https://github.com/Bandoof/CineMatch)**

### 🔢 [Handwritten Digit Recognizer](https://github.com/Bandoof/digit-recognizer) — CNN Desktop App

An interactive application for handwritten-digit recognition with **TensorFlow/Keras**, **OpenCV**, and **Tkinter**.

**Stack:** Python · TensorFlow/Keras · OpenCV · Tkinter

- Drawing canvas, image upload, and webcam mode with adjustable region of interest.
- **99.09% test accuracy on MNIST** in a documented, separately trained five-epoch run (not the bundled legacy checkpoint).
- Reproducible training, evaluation metrics, learning curves, and confusion matrix.
- Automated preprocessing and batched inference options.

**[Source & results](https://github.com/Bandoof/digit-recognizer)**
