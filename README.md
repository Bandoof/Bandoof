### 🔢 [digit-recognizer](https://github.com/Bandoof/digit-recognizer)

**Handwritten digit recognition**

<p>
  <img src="https://img.shields.io/badge/Python-8B5CF6?style=flat-square&logo=python&logoColor=white" alt="Python" />
  <img src="https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white" alt="TensorFlow" />
  <img src="https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white" alt="OpenCV" />
  <img src="https://img.shields.io/badge/Tkinter-14B8A6?style=flat-square&logo=python&logoColor=white" alt="Tkinter" />
</p>

- Desktop CNN app with a drawing canvas, image upload, and webcam input.
- Reproducible training, evaluation reports, and batched inference.
- A separately trained model reached **99.09% on the official MNIST test set** without test-time augmentation. This result does not describe the bundled legacy model or real-world webcam accuracy.

[📂 Repository](https://github.com/Bandoof/digit-recognizer) · [📊 Evaluation results](https://github.com/Bandoof/digit-recognizer/blob/main/reports/README.md)
